# ini-parse-core

Interpretação e serialização de INI: seções, `chave = valor`,
comentários, rejeição de chave duplicada. Zero dependências, Node >= 22.

Parte do laboratório open source da LOFRANO TECNOLOGIA. MIT.

```sh
npm test          # 4 testes, node:test, sem dependências
npm run demo
```

Valores são strings puras; no máximo 1M caracteres. MIT — veja `LICENSE`.
